# F9.3 Instagram

- **Pasul:** F9.3, faza 9. Depinde de F9.1, F9.2. Context: `docs/15` §15.1, §15.3; `docs/06` (linkuri semnate).
- **Hotărâri de proiectare (D-007).**
  - `ConectorInstagram` (Graph API, aceeași autorizare Meta, cont extern = `instagram_business_account`):
    container (`image_url` / `media_type=REELS` + `video_url`) → pentru clip, `status_code` citit până la
    `FINISHED` cu pauze crescătoare (ceas injectat; în teste fără așteptări reale) → `media_publish` →
    `permalink`.
  - Fișierele se servesc prin linkuri semnate care expiră (`publicare.linkuri`, ruta publică
    `/publicare/fisier/<jeton>`): calea relativă și expirarea, semnate HMAC cu cheie derivată din
    `AMA_MASTER_KEY`; semnătură greșită, expirare sau ieșire din directorul media → 404. Valabilitate 6 h [I].
  - Limita se citește din endpoint (`content_publishing_limit`) înainte de fiecare publicare; epuizată →
    eroare temporară (executorul reîncearcă, nu dublează).
  - `verifica`: legenda exactă printre media recente ale contului.
  - Cererea App Review pentru `instagram_content_publish`, cu înregistrarea fluxului (`POST /media_publish`).
- **Contracte.** `connectors.publicare.instagram.ConectorInstagram`, `publicare.linkuri.{semneaza, jeton,
  verifica}`, `publicare.web.router`.
- **Teste de acceptare.** `tests/contract/test_conector_instagram.py` (suita comună; clipul așteaptă procesarea;
  limita din endpoint oprește publicarea); `tests/integration/test_publicare_instagram.py`: **o imagine și un clip
  apar pe contul agenției** (fișierele aduse de „Instagram” chiar prin aplicație, pe link semnat), **iar
  permisiunea de publicare este cerută în App Review**; linkul modificat, expirat sau ieșit din director dă 404.
- **NEVERIFICAT / SIMULAT.** Graph simulat. Contul profesional real, limita reală, timpii de procesare, adresa
  publică (`AMA_PUBLIC_URL`) prin proxy, cererea App Review: la migrare.
