# F13.7 Consiliul

- **Pasul:** F13.7, faza 13 (sesiunea A). Depinde de F13.4–F13.6. Context: `docs/07` §7.6. Migrarea `0074`.
- **Gata când:** o decizie luată în Claude apare în platformă și schimbă starea unei campanii.
- **Hotărâri (D-012).**
  - Dosarul (`consiliu.deschide`): cifrele pe 30 de zile pe campanie, plafoanele, ultimele decizii ale Strategului
    (cu ipotezele), opțiunile (continuă, oprește / repornește o campanie, pivotează) cu acțiunile lor, trei
    întrebări și formatul exact al răspunsului (un bloc JSON: alegere, motive, condiții, ce măsurăm).
  - Importul (`consiliu.importa`) extrage blocul JSON din textul lipit, îl validează, refuză o opțiune care nu e în
    dosar, scrie înregistrarea de decizie (`sursa = consiliu`) și transformă acțiunile opțiunii în propuneri
    `consiliu`, aprobate de omul care a importat (gardian + executor).
  - Modul API (`consiliu.intreaba_api`, promptul `reclame.consiliu.v1`): aceeași ușă; propunerile așteaptă omul.
  - Bugetul de apeluri: `AMA_RECLAME_CONSILIU_PLAFON_LUNAR` (8); peste el dosarul se scrie „amânat”.
- **Ecran:** `/reclame/consiliu` (dosar nou pe cont, lista), `/reclame/consiliu/<id>` (textul de copiat, câmpul
  pentru răspuns). Doar proprietarul.
- **Teste:** `tests/integration/test_reclame_consiliu.py` (manual prin HTTP, plafonul, modul API pe model FALS).
- **NEVERIFICAT:** răspunsul real al lui Claude (aici e scris de test); profilul T4 și creditul lunar al API-ului.
