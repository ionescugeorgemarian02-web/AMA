# F9.5 LinkedIn

- **Pasul:** F9.5, faza 9. Depinde de F9.1–F9.2. Context: `docs/15` §15.1.
- **Hotărâri de proiectare (D-007).**
  - `ConectorLinkedin` pe Posts API (`/rest/posts`, antetele `LinkedIn-Version` și Rest.li 2.0): profilul pe
    canalul `linkedin` (permisiunea `w_member_social`, autorul `urn:li:person:{sub}` din `userinfo`), pagina de
    companie pe canalul separat `linkedin_pagina` (Community Management API, autorul din `organizationAcls`).
  - Profilul are aprobarea „aprobată” de la început (self-serve, 15.1): automat chiar pe contul unui client.
    Pagina are cerința `linkedin/pagina`: asistat până la aprobare (sau pe contul agenției, în modul de test).
  - `verifica`: postările autorului, după text. Limita: LinkedIn nu o expune prin API; se numără postările de
    azi citite din API față de plafonul zilnic documentat (150 [I]).
  - Tokenul (60 de zile); reîmprospătarea doar dacă platforma a dat token de reîmprospătare.
- **Contracte.** `connectors.publicare.linkedin.ConectorLinkedin`, setările `AMA_LINKEDIN_CLIENT_ID`,
  `AMA_LINKEDIN_CLIENT_SECRET`, `AMA_LINKEDIN_VERSIUNE`.
- **Teste de acceptare.** `tests/contract/test_conector_linkedin.py` (suita comună pe profil și pe pagină;
  autorul din cont); `tests/integration/test_publicare_linkedin.py`: **o postare apare pe profilul tău**; pagina
  rămâne asistată până la aprobare, apoi publică pe pagină.
- **NEVERIFICAT / SIMULAT.** Posts API simulat. Aplicația LinkedIn, profilul real, review-ul Community
  Management API, versiunea API și plafonul zilnic: la migrare.
