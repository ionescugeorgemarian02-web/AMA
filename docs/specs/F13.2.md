# F13.2 Citirea rezultatelor Google Ads

- **Pasul:** F13.2, faza 13 (sesiunea A). Depinde de F13.1 (conturi, rezultate, ecran). Fără migrare.
- **Gata când:** cifrele contului agenției din Google Ads apar în panou și coincid cu consola.
- **Hotărâri (D-008).**
  - Adaptorul `app/connectors/reclame/google.py`: `customers/<id>/googleAds:searchStream`, GAQL pe `campaign` și
    pe `ad_group_ad` cu `segments.date`; antetele `developer-token` și (opțional) `login-customer-id` (MCC).
  - `cost_micros` → bani: împărțire întreagă la 10.000. Conversiile (zecimale) se rotunjesc în jos.
  - Același tabel și același ecran ca Meta; erorile Google se clasifică după cod (401 = autentificare).
  - Setări noi: `AMA_GOOGLE_ADS_VERSIUNE`, `AMA_GOOGLE_ADS_DEVELOPER_TOKEN`, `AMA_GOOGLE_ADS_LOGIN_CUSTOMER_ID`.
- **Teste:** `tests/integration/test_reclame_google.py`, `tests/unit/test_reclame_google.py`; Google Ads API
  SIMULAT (`tests/platforme/google_ads.py`, loturi de rezultate, antetul developer-token obligatoriu).
- **NEVERIFICAT:** versiunea API, nivelul de acces (Explorer/Basic), MCC-ul agenției, tokenul OAuth pe canalul
  `google_ads`, fusul orar al contului. La migrare.
