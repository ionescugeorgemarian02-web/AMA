# F9.6 TikTok

- **Pasul:** F9.6, faza 9. Depinde de F9.1–F9.3 (linkurile semnate). Context: `docs/15` §15.1, §15.3, §15.6.
- **Hotărâri de proiectare (D-007).**
  - `ConectorTiktok` (Content Posting API v2), două moduri după auditul aplicației: **ciornă** (`inbox/video/init`,
    clipul ajunge în aplicația creatorului, care îl publică de acolo) înainte de audit; **postare directă**
    (`video/init`) după audit. Fișierul: `PULL_FROM_URL` pe link semnat; starea: `status/fetch` cu pauze
    crescătoare (ceas injectat).
  - Regulile de integrare TikTok: opțiunile creatorului se citesc chiar înainte de previzualizare și de postare;
    omul vede contul (pseudonimul), clipul și legenda, ALEGE vizibilitatea dintre opțiunile contului (fără
    valoare implicită) și interacțiunile; își dă consimțământul explicit (`publicare_consimtaminte`, migrarea
    `0055`, o dată pe versiune). Fără consimțământ sau cu o vizibilitate pe care contul nu o mai are, conectorul
    refuză definitiv. Eticheta AI → `is_aigc`; conținutul comercial → `brand_content_toggle`.
  - Ecranul `/publicare/api/tiktok/<livrabil>` (previzualizarea + consimțământul) arată starea auditului.
  - `verifica`: la postarea directă, lista clipurilor (`video/list`) după titlu; ciornele nu sunt căutabile (o
    ciornă dublă e inofensivă: o publică omul). Limita: clipurile de azi față de plafonul zilnic (15 [I]).
  - Cererea de audit (`tiktok/publicare`) pleacă cu înregistrarea fluxului (`POST …/video/init/`).
- **Contracte.** `connectors.publicare.tiktok.ConectorTiktok`, `publicare.consimtamant`, `publicare.fisiere`,
  `efecte.autorizare.previzualizare`, `media.biblioteca.citeste_activ`, setările `AMA_TIKTOK_CLIENT_KEY`,
  `AMA_TIKTOK_CLIENT_SECRET`.
- **Teste de acceptare.** `tests/contract/test_conector_tiktok.py` (suita comună pe postarea directă; ciorna;
  refuzul fără consimțământ sau cu vizibilitate nepermisă); `tests/integration/test_publicare_tiktok.py`: **fluxul
  respectă regulile lor, cererea de audit este trimisă cu înregistrarea fluxului și starea ei se vede în panou**.
- **NEVERIFICAT / SIMULAT.** API simulat. Aplicația TikTok, auditul, plafonul zilnic, ghidul UX pe aplicația
  reală (inclusiv declarația de muzică) și filmarea fluxului: la migrare.
