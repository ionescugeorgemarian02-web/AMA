# F9.10 Ecranul „Publicare”

- **Pasul:** F9.10, faza 9. Depinde de F9.1–F9.9, F6.6 (ecranul publicării asistate). Context: `docs/18` (ecranul
  14 „Publicare”), `docs/15` §15.2, §15.3.
- **Hotărâri de proiectare (D-007).**
  - `/publicare/canale`: tabelul aprobărilor API (platformă, permisiune, stare, data trimiterii, observații) și,
    pe fiecare cont al fiecărui client, modul efectiv cu motivul lui („automat, în test”, „asistat: …”), expirarea
    tokenului, cererea de reautorizare, pauza, limitele citite de gardian; coada programată (cu legătura spre
    previzualizarea TikTok).
  - Acțiuni (CSRF, `livrabil.aproba`): **trece pe asistat** (programările deschise devin pachete asistate) /
    înapoi pe automat; **reautorizează**: OAuth pornit din panou, întoarcerea la `/publicare/autorizare`. Starea
    OAuth poartă canalul și clientul (`canal.client.nonce`), verificată prin HMAC și folosită o singură dată.
  - Ecranul asistat (`/publicare`) și cel prin API se leagă între ele.
- **Contracte.** `panou.publicare_canale_web.router`, `canale.incepe_oauth` (starea cu clientul).
- **Teste de acceptare.** `tests/integration/test_publicare_ecran.py`: **vezi starea fiecărei aprobări API și poți
  trece un canal pe asistat** (și înapoi); reautorizarea din panou (o stare folosită o singură dată); fără CSRF,
  refuz.
- **NEVERIFICAT / SIMULAT.** Platforma falsă. Ecranul pe telefonul real, adresa publică de întoarcere OAuth
  înregistrată la fiecare platformă: la migrare.
