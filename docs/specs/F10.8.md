# F10.8 Analistul de reclame ale concurenței (C3)

- **Pasul:** F10.8, faza 10. Depinde de F4.2 (documentele colectate), F5.6 (G7). Context: `docs/12` §12.6, §12.1.
- **Hotărâri de proiectare (D-007).**
  - **Sursa:** Meta Ad Library API (`ads_archive`, reclamele livrate în România), cu `AMA_META_AD_LIBRARY_TOKEN`
    în antet. Fără token, jobul nu citește nimic. Biblioteca TikTok („de verificat” în 12.1) nu e citită.
  - **Concurenții urmăriți** (`concurenti_reclame`): nume și identificatorul paginii Meta, adăugați din panou.
  - **Reclamele observate** (`reclame_observate`, migrarea `0061`): text, platforme, perioada de livrare, unghiul.
    A doua citire actualizează perioada, nu dublează.
  - **Se analizează, nu se copiază:** textul fiecărei reclame intră în documentele colectate ale clientului, sub
    o sursă cu statutul nou `meta_ad_library` (text nereutilizabil). **G7 blochează astfel un text prea apropiat
    fără nicio schimbare în validare.**
  - **Unghiul pe reguli:** opt categorii (preț, urgență, dovadă socială, garanție, noutate, calitate,
    comoditate, local), prima potrivită câștigă, altfel „alt unghi”. Gruparea cu model (partea „L · T2” a lui
    C3) nu este construită.
  - **Harta unghiurilor** (`harta`): reclame pe concurent și unghi, reclamele care rulează de cel mai mult timp,
    spațiile libere (unghiuri nefolosite de niciun concurent urmărit). Ecran: `/analiza/concurenta`.
  - Job `cercetare.reclame`: luni, 06:30, ora României. O pagină necitită nu le oprește pe celelalte.
- **Teste de acceptare.** `tests/integration/test_cercetare_reclame.py`: **harta unghiurilor cu reclamele de
  durată, iar un text prea apropiat de o reclamă observată este blocat de G7** (validatorul real; un text
  original trece); pagina căzută; a doua rulare; clienți separați; ecranul și CSRF; fără token nu se face nicio
  cerere. `tests/unit/test_cercetare_reclame.py`: unghiul, durata, răspunsul bibliotecii, harta.
- **NEVERIFICAT / SIMULAT.** Biblioteca e simulată. Pe un token real: câmpurile disponibile pentru reclamele
  comerciale din UE, paginarea (acum doar primele 100 pe pagină Meta), limitele de rată. Lista de cuvinte pe
  unghi e de pornire.
