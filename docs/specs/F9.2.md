# F9.2 Facebook, pagini

- **Pasul:** F9.2, faza 9. Depinde de F9.1. Context: `docs/15` §15.1, §15.3, §15.7.
- **Hotărâri de proiectare (D-007).**
  - `ConectorFacebook` (Graph API): OAuth Meta → token scurt → token lung → tokenul paginii (`me/accounts`); tokenul
    paginii primește expirarea tokenului lung (60 de zile [I]), ca gardianul să ceară reautorizarea la timp.
    Publicare `POST /{pagina}/feed`, apoi `permalink_url`. Tokenul doar în antetul `Authorization`; schimbul de cod
    prin `POST` (secretul aplicației nu apare în adrese).
  - `verifica`: Graph nu are cheie de idempotență, deci se caută textul exact în `published_posts`.
  - Erorile Graph: codul 190 = token; `is_transient` și codurile de limită (1, 2, 4, 17, 32, 341, 613) =
    temporare; restul 4xx = definitive. Limitele: procentul din `X-App-Usage` / `X-Page-Usage` /
    `X-Business-Use-Case-Usage`.
  - Cererea de App Review (`publicare.aprobari`): pleacă doar cu înregistrarea fluxului real în modul de test
    (pașii HTTP ai OAuth-ului și ai publicării, fără parametri, corpuri sau tokenuri, prin
    `efecte.autorizare.inregistreaza_fluxul`), cu descrierea cazului de utilizare; înregistrarea trebuie să conțină o
    publicare reușită. Starea trece în „trimisă”; baza refuză „trimisă” fără înregistrare. Decizia platformei
    (`decide`) e notată de om: respinsă = canalul rămâne asistat.
  - Conectorii reali se încarcă la cerere doar pentru canalele din `AMA_PUBLICARE_CONECTORI` (implicit niciunul).
- **Contracte.** `connectors.publicare.facebook.{ConectorFacebook, ConectorMeta}`, `publicare.aprobari`,
  setările `AMA_PUBLIC_URL`, `AMA_PUBLICARE_CONECTORI`, `AMA_META_APP_ID`, `AMA_META_APP_SECRET`,
  `AMA_META_GRAPH_VERSIUNE`.
- **Teste de acceptare.** `tests/contract/test_conector_facebook.py` (suita comună pe Graph simulat);
  `tests/integration/test_publicare_facebook.py`: **o postare de test apare pe pagina agenției, o singură dată**
  (și după un răspuns pierdut), **iar cererea de App Review pleacă împreună cu înregistrarea fluxului**; fără
  publicare reușită în înregistrare, cererea nu pleacă.
- **NEVERIFICAT / SIMULAT.** Graph API simulat (`tests/platforme/meta.py`). Aplicația Meta, pagina agenției, versiunea
  Graph, depunerea în App Dashboard și filmarea fluxului: la migrare.
