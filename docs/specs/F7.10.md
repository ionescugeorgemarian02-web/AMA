# F7.10 Cercetarea SEO și articolele (C6, E5, E7)

- **Pasul:** F7.10, faza 7. Depinde de F7.1 (blogul), F5 (validare), F6 (editorul). Context: `docs/13`, `docs/05`.
- **Hotărâri de proiectare (D-007).**
  1. C6: grupuri de cuvinte-cheie pe intenție, deterministe (reguli [I]: informațională, comercială, tranzacțională,
     locală; termen-cap). Volumele de căutare cer o sursă externă: la migrare.
  2. Brieful SEO determinist (principal, secundare, intenție, surse numerotate); articolul în trei pași prin gateway
     (plan, scriere E5, editare E7) plus editorul determinist din F6.
  3. Lista on-page deterministă: titlu 30–65 cu cuvântul principal, descriere 120–160, adresa, primul paragraf,
     ≥ 3 subtitluri, ≥ 450 de cuvinte [I], densitate ≤ 3% [I], ≥ 2 surse citate, nicio citare fără sursă.
  4. Validarea: cascada deterministă întreagă (vectorii omiși, listați); citările [n] nu intră în textul validat.
     Doar articolul care trece amândouă se publică pe blogul agenției, cu sursele efectiv citate.
- **Contracte.** `seo.cuvinte.{grupeaza, intentie}`, `seo.articole.{brief, scrie, verifica_on_page}`; trei prompturi
  `seo.*@1`.
- **Teste de acceptare.** `tests/integration/test_seo_articole.py`: **două articole pentru blogul agenției trec
  validarea și lista on-page și apar pe blog cu sursele citate (sursa necitată lipsește)**; lista prinde problemele.
- **NEVERIFICAT / SIMULAT.** Modelele reale, sursele reale (din cercetare, F10), volumele de căutare: la migrare.
